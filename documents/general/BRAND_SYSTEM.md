# ABL-inspired visual identity for the demonstration

## Boundary

This is an ABL-inspired internal demonstration identity derived from ABL's public website and public advertising. It is not an official ABL brand guide, and the project does not reproduce or claim ownership of an official ABL logo, licensed font or private brand asset.

## Public cues used

- Restrained, premium editorial presentation rather than a generic software-dashboard aesthetic.
- Dark tonal fields, clean navigation, strong hierarchy and generous whitespace.
- A warm, controlled accent rather than a broad multicolour palette.
- A serif display voice paired with direct sans-serif interface text.
- ABL's public emphasis on judgement, responsiveness, direct access and assistance “when it matters most.”

## Design tokens

| Category | Token | Value / role |
|---|---|---|
| Colour | `--abl-charcoal` | `#171716`, primary text and dark fields |
| Colour | `--abl-paper` | `#f2efe8`, page ground |
| Colour | `--abl-white` | `#fffefb`, content surfaces |
| Colour | `--abl-accent` | `#c94f32`, restrained warm emphasis |
| Colour | `--abl-sand` | `#e8dfd2`, secondary controls |
| Typography | `--abl-font-display` | Georgia fallback stack for editorial headings |
| Typography | `--abl-font-body` | Arial/Helvetica fallback stack for interface clarity |
| Spacing | `--abl-space-1` to `--abl-space-6` | 6px to 72px scale |
| Shape | `--abl-radius-sm/md/lg` | 2px, 6px and 12px; restrained rather than pill-heavy |
| Rule | `--abl-rule` | consistent charcoal divider |
| Depth | `--abl-shadow` | subtle elevation only where hierarchy needs it |

## Application rules

- Use charcoal for authority, governance and major navigation surfaces.
- Use the warm accent for emphasis, current state and links—not as decoration everywhere.
- Use success, warning and danger colours only for system state.
- Keep cards square or lightly rounded; avoid consumer-app pills and excessive gradients.
- Use generous whitespace and concise copy so evidence remains the focus.
- Do not introduce an ABL logo until an approved asset and usage permission are provided.
